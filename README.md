# Infrastructure as Code for Staging Environment

## Mini Project 2.2

This project demonstrates Infrastructure as Code (IaC) using Terraform.

The objective is to provision a reproducible staging environment through automation rather than manual configuration.

## Technologies

- Terraform
- Docker
- Git
- GitHub Actions
- PowerShell

## Infrastructure

- Application Server
- PostgreSQL Database
- Docker Network

## Features

- Infrastructure as Code
- Automated Provisioning
- Version Controlled Infrastructure
- CI/CD Validation
- Destroy and Recreate Demonstration
